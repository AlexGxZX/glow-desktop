## Следующее обновление

### Синхронизация с телефоном по Wi-Fi
Glow для Android уже умеет делиться данными по Wi-Fi: в его настройках есть переключатель, адрес и шестизначный код. Glow для ПК научится подключаться к телефону и переносить плейлисты, избранное, оценки, счётчики и историю — то же, что файл `.glowsync`, только без файлов. Раздел «Система → Синхронизация с телефоном»: адрес, код, кнопка «Синхронизировать» и автосинхронизация в одной сети.

## Обновление дизайнов: у каждого стиля своё лицо

Сейчас у большинства стилей одинаковые частицы и фон, а темы Material 3 отличаются только палитрой. Вместо новых стилей каждый существующий получает свою **подпись**: фон, частицы, вид обложки или сцену и характер. Основа Glow сохраняется — свечение от обложки, стиль и частицы; стекло только там, где оно уместно.

### Сцены
Свои центры экрана плеера, детальные, со свечением цветом обложки и частицами, которые рождаются из самого объекта:
- **Светящийся винил** — пластинка с сиянием по краю, блики в бороздках, искры с иглы на ударах.
- **Кассета** — детальный корпус, катушки подсвечены изнутри, плёнка перематывается по ходу трека, светящаяся пыль.
- **Светодиодная матрица** — обложка из диодов с ореолом; при смене трека рассыпается и собирается заново.
- **Ночной город** — окна и вывески в цветах обложки, зарево, светящийся дождь.
- **Жидкий свет** — светящиеся капли, сливаются и раздуваются на басах.
- **Светящаяся планета** — обложка-планета с атмосферой, кольца из пыли, луны-треки.

## Потом

### Звуковое ядро на Rust
Отдельное большое обновление: воспроизведение через Rust вместо движка браузера.
- Все форматы: ALAC, APE, WavPack, AIFF, WMA, DSD.
- Настоящий переход без пауз, с точностью до сэмпла.
- Выбор устройства вывода, эксклюзивный режим WASAPI.
- Подсчёт громкости в фоне без нагрузки на интерфейс.

### Остальное
- Подпись установщика, чтобы Windows не предупреждала (SignPath для открытых проектов).
- Чтение `.glowsync` и `.glowtheme` в Android-версии.
