# Планы Glow для ПК

Что уже решено сделать. Порядок внутри обновления может меняться.

## Главное правило: без интернета
Glow — локальный плеер. Воспроизведение, медиатека, синхронизация с телефоном (она идёт по локальной сети, интернет для неё не нужен) — всё работает офлайн. Онлайн-функции — только дополнение: найденные тексты и обложки сохраняются у себя, скробблинг копится и отправляется, когда интернет появится.

## 2.0 — Glow как экосистема

Большая версия: то, что меняет сам плеер, а не только его вид.

### ПК и телефон: одна медиатека
Модель «ПК — главная медиатека, телефон — её часть», как iPod и iTunes, только по Wi-Fi в домашней сети.
- Вся коллекция живёт на ПК. В Glow на ПК отмечаешь, что должно быть на телефоне: плейлисты, альбомы, избранное, «последние N добавленных».
- Glow сам передаёт на телефон недостающие файлы (с обложками, тегами и `.lrc`) и убирает снятое с отметки. Докачка при обрыве, проверка свободного места и целостности файлов.
- Каждый переданный трек получает постоянный ID, поэтому дальше треки на обоих устройствах совпадают точно.
- Затем синхронизируются данные: прослушивания, оценки, избранное, история возвращаются с телефона на ПК.
- Музыку, скачанную прямо на телефон, Glow на ПК предлагает забрать в коллекцию.
- Потом: слушать всю медиатеку ПК с телефона по домашнему Wi-Fi без копирования.

Основа уже есть в Android-версии: поиск через mDNS (`_glow._tcp`), HTTP-сервер на порту 47800, шестизначный код. Нужно добавить список файлов, передачу файлов в обе стороны и постоянные ID; удаления, конфликты и постоянный ключ вместо кода — решить в протоколе.

### Звуковое ядро на Rust
Отдельное большое обновление: воспроизведение через Rust вместо движка браузера.
- Все форматы: ALAC, APE, WavPack, AIFF, WMA, DSD.
- Настоящий переход без пауз, с точностью до сэмпла.
- Выбор устройства вывода, эксклюзивный режим WASAPI.
- Подсчёт громкости в фоне без нагрузки на интерфейс.

### Остальное
- Подпись установщика, чтобы Windows не предупреждала (SignPath для открытых проектов).
- Чтение `.glowsync` и `.glowtheme` в Android-версии.

- **1.11** — вкладки и поиск в настройках.
- **1.10** — автообновление через GitHub Releases, автотесты, сборка на GitHub, код разбит на модули.
